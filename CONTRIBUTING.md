# Contributing Guidelines

Thank you for your interest in contributing to the WhatsApp Missed Call Auto-Responder project!

## Getting Started

1. Fork the repository on GitHub.
2. Clone your fork locally:
   ```bash
   git clone https://github.com/<your-username>/whatsapp-missed-call-responder.git
   ```
3. Open the project in Android Studio (Koala, Ladybug, or newer).
4. Create a feature branch:
   ```bash
   git checkout -b feature/my-new-feature
   ```

## Development Workflow

- Build the project using the Gradle wrapper:
  ```bash
  ./gradlew assembleDebug
  ```
- Follow official Kotlin coding conventions.
- Test your changes on a physical device or emulator.

## Submitting Pull Requests

1. Commit your changes with clear, descriptive commit messages.
2. Push your branch to GitHub.
3. Open a Pull Request against the `main` branch.
