# Security Policy

## Reporting Security Issues

We take the security and privacy of this application seriously.

If you discover a security vulnerability or privacy concern, please do not disclose it publicly in issues or discussions. Instead, report it privately to the repository maintainer.

Please provide:
- A description of the issue.
- Steps to reproduce or proof of concept.
- Affected Android versions or devices.

We will review reports promptly and work to resolve confirmed issues in upcoming releases.
